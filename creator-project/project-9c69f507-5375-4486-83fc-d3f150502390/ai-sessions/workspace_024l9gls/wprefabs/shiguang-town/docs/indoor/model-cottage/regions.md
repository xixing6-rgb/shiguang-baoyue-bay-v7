# 《时光小筑主木屋》区域与陈设布局（Stage 2: Regions）

## 1. 局部坐标与净空契约
- 室内净地面范围：`X ∈ [-3.38, +3.38]`（宽 `6.76m`）、`Z ∈ [-2.48, +1.28]`（深 `3.76m`），地坪完成面 `Y = 0.24m`。
- 入户门洞：`X ∈ [-0.75, +0.75]`、`Z = +1.39`、`Y ∈ [0.24, 2.49]`；`DoorPivot` 位于 `(-0.73, 0.24, 1.39)`，开启时向室内 `-Z` 靠西贴侧旋转 `+86°`，保持 `X > -0.60` 全幅入户通廊畅通。

## 2. 四大功能区与资产组合

| 区域 | 局部坐标中心 | 主体资产与朝向 | 配套与使用细节 | 通行与操作留白 |
| :--- | :--- | :--- | :--- | :--- |
| **入户玄关与前廊** | `(0, 0.24, +1.3~+2.98)` | 双级入户木阶、挑檐廊台、`DoorPivot` 拱顶木门 | 两侧矮木栏杆、双侧窗台彩色花箱、门右悬吊暖光小提灯 | 门前保留 `1.5m` 宽直线步入带 |
| **中央茶叙区** | `(+0.35, 0.24, -0.80)` | 圆角实木矮茶桌（面向四周开放） | 东西对称摆放 2 个编织圆垫，桌面配 2 只带柄陶土茶杯与小饼干盘 | 距门洞内侧与西书架均保持 `≥ 1.1m` 绕行宽度 |
| **北东暖炉区** | `(+2.35, 0.24, -1.75)` | 石砌转角壁炉（朝向 `(-X, +Z)` 中央茶叙区） | 炉膛叠放木柴与橙黄自发光余烬芯，壁炉台摆 2 个小陶罐 | 前方留出 `1.2m` 烤火观察区 |
| **西墙阅读区 & 北墙焦点** | 西墙 `(-2.95, 0.24, -1.0)`；北墙 `(0, 1.72, -2.44)` | 矮木三层书架（面向 `+X`）、12×12 像素太阳画框（面向 `+Z`） | 书架内排布 12 本彩色精装书与顶部小绿植盆栽；人字木地板铺满全室 | 书架前 `1.3m` 净空便于角色靠近阅读 |

## 3. 墙、地、顶与视觉统一
- **地面**：512×512 程序化人字拼花暖橡木地板纹理 + 独立 `roughnessMap`。
- **墙面**：外墙暖蜂蜜横板、内墙低噪点奶油白木板（与暖木柱踢脚线收边）。
- **屋顶**：室内可见双坡木屋架横梁，外观为五层错缝暖陶红圆角屋瓦与高出屋脊的石砌烟囱。
