# 《时光小筑主木屋》设计文档（Stage 0: Style & Design）

## 1. 范围、尺度与接口约束
- **建筑定位**：单层可进入温馨海滨疗愈木屋（对应地图槽位 `cottage-main`，slot `cottage`）。
- **外部包络**：宽度 `8.0m`（X: `-4.0 ~ +4.0`）、进深 `6.0m`（Z: `-3.0 ~ +3.0`，包含前廊台 `1.15m`）、总高 `4.8m`（含双坡暖陶瓦顶与烟囱）。
- **语义朝向与标高**：局部 `+Y` 向上、`+Z` 为入户正面（朝向庭院与南侧大海），底层入口门廊完成面及台阶脚踏面落在局部 `Y = 0`；实际地面木底板顶面为 `Y = 0.24m`，前廊设 2 级平稳踏阶（每级 `0.12m` 高、`0.35m` 深）顺滑连接地面 `Y = 0` 到室内地坪 `Y = 0.24m`。
- **可穿行门洞与可动件**：正南墙居中设净宽 `1.50m`、净高 `2.25m` 的无遮挡真实门洞；独立 `DoorPivot` 位于门洞左侧门框铰链点 `(-0.71, 0.24, 1.84)`，初始局部旋转 `[0,0,0]`（关闭态），由 Lua 驱动绕 Y 轴向外/向内平滑旋转 `90°` 开启。

## 2. 参考提取的视觉身份特征（对照 `#01/#02/#04` 参考图）
- **体量比例**：厚实温暖的圆木拼板墙体 + 略微外挑的廊檐与圆润粗木廊柱 + 厚片层叠式暖陶红屋瓦（带白色檐口收边与独立石砌烟囱）。
- **开口节奏**：正面居中拱圆角木门两侧对称分布十字木格暖光大窗，东西两侧各开一扇田字格玻璃窗，室内外采用同一窗洞开孔，透光通透。
- **材质角色分工**：
  - 浅原木墙与地板（`#E4BA8B`，人字拼花 CanvasTexture）
  - 奶油木纹内壁（`#FFF5E4`，柔和低噪点横条板纹）
  - 暖陶红瓦片顶（`#B96A59`，哑光粗糙度 `0.78`）
  - 深蜂蜜木梁与窗框门板（`#9D623E`，勾勒结构边缘）
  - 暖石壁炉与外阶底座（`#C2B5A3`）
  - 自发光暖灯芯与暖窗框点缀（`#FFD67A`，仅用于炉芯火炭与门廊小灯笼，窗洞保持透空或极低透明暖玻璃 `opacity: 0.22`）

## 3. 室内功能区与必做/可选陈设
- **必做核心构造与家具**：
  1. 闭合实体外墙（带真实 1.5×2.25m 门洞与 4 个窗洞，不留零厚度封闭片阻挡穿行）。
  2. 人字拼花木地板 + 双坡屋顶内梁架。
  3. **中央茶叙区**：圆角实木茶桌 + 2 个编织质感圆垫 + 2 只陶土茶杯。
  4. **北角暖炉区**：石砌壁炉 + 烟道 + 炉膛木柴与温暖橙红余烬自发光火芯。
  5. **西墙阅读区**：矮木书架 + 12 本多色精装书 + 1 盆圆润绿植盆栽。
  6. **北墙视觉焦点**：12×12 像素太阳爱心木框挂画（CanvasTexture 精确像素绘制）。
  7. **外廊交互配套**：入户木阶、双侧矮栏杆、两个彩花外窗花箱、门旁暖黄小提灯。
- **留白设计原因**：保留中央和入口 `≥ 1.2m` 宽敞人行通廊，保证 `Avatar` 主角步入和转身视野开阔、不拥挤卡脚。
- **代表视角**：外观 3/4 斜俯图看体量、廊台与瓦顶；运行态进屋实测看门洞开启、茶桌、壁炉与像素挂画。
