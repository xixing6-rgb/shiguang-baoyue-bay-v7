## 第一部分：叙事哲学与四条反体验污染红线

《时光小筑》剥离一切商业化逼氪、每日打卡与剥夺性倒计时，将《集合啦！动物森友会》的**“疗愈型空间仪式与异步人际连接”**与《朋友收集：梦想生活》的**“自主意志社会剧场与圈内梗涌现”**合二为一：

1. **红线一 · 零缺席惩罚（Zero Absence Penalty）**：无论玩家阔别几天或数月，居民好感度（`0–255`）衰减恒为 `0`。海滩上的漂流瓶与长出来的野花只代表“海风还在认真吹过”，绝不触发任何责备或进度回退。
2. **红线二 · 零失败状态与零倒计时焦虑（Zero Fail State）**：不存在 Game Over、饥饿值扣减、限时任务失效或强迫每日签到。五幕章节的推进全部由**“修复微设施（灯塔/灯船/温室/拱桥）的好奇与温柔反馈”**驱动。
3. **红线三 · 克制轻推边界（Nudge, Never Command）**：玩家可以通过物理抓起轻推（`つまむ`）、投喂食物或布置设施改变空间引力，但**绝不提供“强制某两位居民立刻相爱/服从”的控制面板**。居民被放下后可能会乖乖互动，也可能面瘫鼓掌、呆盯三秒或扭头走开——“不配合的意外”才是自主生命感的来源。
4. **红线四 · 可预测的正向微回报与表意留白（Predictable Micro-Feedback & Sukima）**：每一次浇花、摇树、投喂、修缮与按 `E` 触发交互均有清脆温柔的视听回响；严格限定平台官方动作白名单（`walk / run / greet / wave / sit / clap / cheer / dance / photo / water_bend` + 节点程序动效 `turn_to_player / hop_bounce / nod_tilt / hover_bob / door_open / pivot_spin / paper_pet_squash` + 四色气泡与轻量粒子），**严禁手指精细动作、面部嘴型动画或跳跃攀爬**，把情感呼吸留给声音的“スキマ（缝隙）”与玩家的“面具投射”。

## 第二部分：世界观前史——海风里的“时光小筑”

### 2.1 为什么老镇叫“时光小筑”？
三十多年前，这片三面环水、呈月牙状抱合翡翠内湾的小小半岛还不叫“时光小筑”，只是一座供渔船躲风的**风铃湾渡口**。  
第一批在此定居的老居民——在西岬看灯塔的守夜人、在东湾造木船的师傅、以及总爱把云朵抄写进笔记本里的林间学者——发现这里有一桩奇事：**别处的浪头总是催着人赶早班船，只有这座海湾的潮水退得慢、晚霞落得迟，风一吹过廊檐，连时间都像在晒暖阳**。  
于是他们合力在海湾正中（`(-10, +1.8, -2)`）建起一栋暖陶红瓦的小木屋 `F04`，门楣上画了一枚太阳与海浪交叠的木徽，取名**“时光小筑”**——意思是：**“把赶路的时间暂借一角给海风歇脚的小屋。”**

### 2.2 未寄出的信件是从哪里来的？
随着岛湾一天天安静下来，年轻的朋友们陆续乘着草帽狐狸阿澈驾驶的潮汐小船**“白昼号”**去往远方求学、工作。离开之前，大家总会来老镇走一圈；留下来的老街坊也习惯把“当时有点害羞、没当面说出口的话”写成明信片：
- 写给刚上船却忘记带伞的同行者；
- 写给第 37 次把面包烤焦却假装那是“焦糖风味”的自己；
- 写给未来某天会重新踏上登岛码头 `F01` 的新旅人。

本来这些信应该放进西翼 `F19 风铃旧邮局` 寄往海那头，可某年季风吹断了邮局的玻璃风铃绳，邮筒门被藤蔓缠住，邮差水獭团团又迷糊着把邮票簿塞进了阁楼深处。久而久之，**“没寄出去的心愿与问候”**全都留在了邮局木柜、沙滩漂流瓶 `F03` 和北林树洞 `F36` 里。只有从不爱说话、总是面无表情慢拍鼓掌的**橘猫阿橘**，在别人睡着以后，偷偷用小爪子把被风吹散的旧信一封封拾起，按颜色码进了信箱画廊 `F20`。

### 2.3 2D 纸片宠物与 12×12 像素旗的由来
在《时光小筑》的世界观里，为什么 3D 软萌黏土风的小镇中会出现**自带白边、会靠正弦挤压拉伸一蹦一跳跟着人走的 2D 纸片涂鸦宠物（`U01`）**，以及挂满街角的 **12×12 像素旗（`F07`）**？  
这正源自“白昼号”停航前大家立下的**纸片约定**：
> *“如果要去很远的地方、不能每天在长椅上碰面，就把今天想陪你散步的心情，用马克笔剪成带白边的硬纸片，插在小底座上留在‘时光石’（`F18`）旁边吧。只要风还在吹、黑板还写着只有我们懂的奇怪流行语，纸片小狗和纸片猫就替我们继续摇尾巴。”*

正因为这份“把思念画成轻拼贴、让不完美的涂鸦也理直气壮地活在 3D 小镇里”的镇史底色，玩家亲手绘制的歪歪扭扭 12×12 像素小旗、涂鸦黑板流行语与纸片宠物，才天然拥有与主线灵魂同频的情感重量。

- `timeSlot`（`afternoon` / `dusk` / `night`）
- `weather`（`sunny` / `breeze` / `rain` / `starlight` — 由确定性气象种子生成）
- `yesterdayAction`（如 `watered_flower` / `fed_bun` / `nudged_cat` / `changed_flag` / `rode_slide`）
- `affectionTier`（`1..5`）、`zone`（`Zone0/W/E/N/S`）、`quirk`、`playerLingo`、`lastEncounter`

**匹配法则**：检索所有满足前提条件的台词，按 **`matchCount`（命中条件数越多越具体，优先胜出）→ `priority` → 冷却防复读（至少间隔 180 秒或 6 句对话不重样）** 选出唯一响应，确保 NPC 自然说出 *“听说你昨天傍晚顶着海风在花圃试了三轮蓝玫瑰杂交”* 这种极强在场感的鲜活台词。

### 6.2 Tracery 递归词库与《风铃湾小报》新闻模板
支持玩家在 `F08 庭院涂鸦黑板` 或 `F41 漂流书屋` 注入任意自创流行语 `#lingo#`、纸片宠物名 `#petName#` 与 12×12 像素旗标题 `#flagTitle#`，由 `blackboard-dialogue-engine.lua` 进行最多 5 层安全递归展开：
- `#newsHeadline#` → `【风铃湾整点怪闻】今日 #resident# 在 #facility# 一本正经地宣布：“全岛最时髦的事就是 #lingo#！” #quirkReaction#`

- `#concertLyric#` → `♪ 晚霞落进潮汐线，大家一起把 #lingo# 挂上 #flagTitle# 飘起来 ♪`
