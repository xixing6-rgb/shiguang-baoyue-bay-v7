### 1.3 手机端窄幅胶囊对话框与安全区避让规范

依据 `preproduction-plan.md` 与 `09-ui-player-view-hud.png` 的官方 HUD 安全避让约束（需避让左上官方栏、右侧系统操作区与左下虚拟摇杆），对话 UI 采用底部居中窄幅奶油胶囊板，严格限制单屏文本行数不超过 2 行：

### 1.4 `DouyinDataStore` 6000 字节上限极简存档设计

为把 `DouyinDataStore` 单条 6000 字节额度留给 12×12 像素旗、孟德尔花卉基因与黑板流行语，本剧本系统**零文本历史存储**，全部 30 幕进度与分支记忆仅压缩为 4 个极简字段：

```json
{
  "charStages": [0, 0, 0, 0, 0, 0, 0, 0, 0],
  "choiceMask": 0,
  "duoMask": 0,
  "duoChoiceMask": 0
}
```

- **`charStages`（9 元整数数组，按 `C01`–`C09` 顺序，取值 `0..3`）**：极限序列化 `{"charStages":[3,3,3,3,3,3,3,3,3]}` 仅占 **34 字节**（远低于 `< 80 B` 指标）。
- **`choiceMask`（27 位无符号整数）**：第 `charIndex * 3 + (stage - 1)` 位记录玩家在该幕选择了 `0`（选项 A）或 `1`（选项 B），供后续黑板事实规则库做彩蛋回响（Lua 5.3 64 位整数与 JS 53 位安全整数均原生无损支持）。
- **`duoMask` & `duoChoiceMask`（各 3 位整数）**：记录 `D01–D03` 已触发状态与选择分支。
- **全量最坏字节占用**：仅 **87 字节**（占 6000 字节上限的 **1.45%**）。

```lua
-- Hamlet Lua 5.3 极简读写参考（0 额外文本存储）
local function markStageDone(save, charIdx0, stage1to3, choiceBit)
    save.charStages[charIdx0 + 1] = stage1to3
    local bitIdx = charIdx0 * 3 + (stage1to3 - 1)
    if choiceBit == 1 then
        save.choiceMask = save.choiceMask | (1 << bitIdx)
    else
        save.choiceMask = save.choiceMask & ~(1 << bitIdx)
    end
end
```

## 五、离线 HTML5 与抖音造世界接入指南

### 5.1 离线 `file://` HTML 游戏直接挂载
在 HTML 文件中通过 `<script src="workspace/data/character-mini-scripts.js"></script>` 即可绕过浏览器 `file://` CORS 限制，直接读取全局对象 `window.SHIGUANG_MINI_SCRIPTS`：

```javascript
// 查询指定居民下一幕可触发的小剧本
function getNextScriptForChar(charId, charStages) {
  const data = window.SHIGUANG_MINI_SCRIPTS;
  const charDef = data.characters.find((c) => c.id === charId);
  if (!charDef) return null;
  const currentStage = charStages[charDef.stageIndex] || 0;
  return charDef.scripts.find((s) => s.trigger.requireStage === currentStage) || null;
}
```

### 5.2 自动化校验基线

1. `character-mini-scripts.json` 与 `character-mini-scripts.js` 语法合法、内嵌数据完全一致；
